# AppExchange Exploration

Salesforce AppExchange already has scheduling and loyalty apps that solve pieces of this problem (class scheduling tools, points/rewards apps). They're a useful sanity check on expected functionality, but this project deliberately builds a **custom native solution** instead of installing a package, in order to:

- Demonstrate core platform skills: custom objects, relationships, Flow Builder automation, sharing/security model, and dashboards.
- Keep full control of the data model and automation logic for a project used as a portfolio/learning piece.

**Decision:** build native. Revisit AppExchange only if a future phase needs something genuinely out of scope for a custom build (e.g. payment processing — see the Phase 7 integration backlog).
