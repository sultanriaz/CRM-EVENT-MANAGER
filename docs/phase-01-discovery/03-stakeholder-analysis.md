# Stakeholder Analysis

| Stakeholder | Role | Needs |
|---|---|---|
| **Members** (end users) | Customers of the fitness studio | Seamless, self-service booking; a transparent view of their own engagement/loyalty |
| **Studio Staff / Trainers** (internal users) | Run day-to-day operations | Simple, efficient tools to manage schedules, track attendance, resolve member issues |
| **Admins** | Configure and maintain the platform | Control permissions, keep the platform running smoothly |
| **Management / Studio Owner** (business sponsors) | Decision-makers | Real-time, trustworthy metrics to drive strategy and growth |
